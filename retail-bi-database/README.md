# Retail BI Database and ETL

## The question

The unglamorous half of analytics. A report is only as good as the database underneath it.

## Approach

1. Designed a retail schema and built the ETL process to load it
2. Profiled slow queries with EXPLAIN and added indexes where they actually helped
3. Set up users and privileges rather than working as root
4. Implemented backup and recovery, including encrypted backups

## Tools

MySQL, DBeaver
