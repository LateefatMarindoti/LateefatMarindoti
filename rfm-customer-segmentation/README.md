# RFM Customer Segmentation

## The question

Not every customer is worth the same marketing spend. RFM is the cheapest reliable way to find out which ones are.

## Approach

1. Loaded a cloud-hosted retail transaction dataset into Databricks
2. Scored roughly 4,300 customers on recency, frequency and monetary value using PySpark
3. Grouped scores into 8 segments
4. Wrote a plain-language description of how a marketing team should treat each segment

## Tools

Databricks, PySpark, Spark SQL
